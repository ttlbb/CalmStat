# CalmStat

一个安静、轻量的 macOS 菜单栏系统监控工具。

菜单栏会实时显示：

- Swap 状态标识 `S`（使用 Swap 时，`S` 与 `MEM` 同时变红）
- CPU 使用率
- 内存使用率
- 系统磁盘使用率
- 网络下载 / 上传速率（默认显示在可拖动的悬浮窗中）

网络悬浮窗默认位于屏幕左上方，可以拖到任意位置并会自动记忆位置。未使用 Swap 时背景为中性灰色；只要内存开始使用 Swap，背景就会变红。点击菜单栏文字可以查看 Swap 已用/总量、开关悬浮窗与其他显示项，以及选择 1、2 或 5 秒刷新频率。

菜单中的“开机启动”使用 macOS 原生登录项服务。若显示“需要批准”，点击该菜单项会打开“系统设置 → 通用 → 登录项”。

## 环境

- macOS 13 或更高版本
- Xcode Command Line Tools

## 构建

```bash
./scripts/build-app.sh
```

应用会生成在 `dist/CalmStat.app`。双击即可运行，也可以拖入“应用程序”文件夹。

首次本地构建运行时，如果 macOS 阻止打开，可在 Finder 中右键应用并选择“打开”。

## 开发

```bash
make test
make app
```

退出应用：点击菜单栏中的 CalmStat 数据，然后选择“退出 CalmStat”。
